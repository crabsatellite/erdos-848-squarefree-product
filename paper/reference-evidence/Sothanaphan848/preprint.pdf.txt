Moreover, equality is attained by [N ]∩{n ∈ Z : n ≡ 7 (mod 25)}, and also by [N ]∩{n ∈ Z : n ≡ 18
(mod 25)} whenever the latter has the same cardinality.

    The proof follows Sawhney’s overall structure. We partition A according to its residue classes
modulo 25, write A7 and A18 for the two distinguished classes, and let A∗ denote the union of
the remaining classes. The final case analysis is the same as in [2]; the main task is to make two
auxiliary estimates explicit.
    The first estimate concerns squarefree numbers in a fixed arithmetic progression. Here we use
a self-contained Möbius-splitting argument, in the spirit of Prachar and Hooley [3, 4], to obtain
an explicit replacement for Sawhney’s Lemma 2.2. The second estimate bounds the number of x
for which x2 + 1 has a square factor; this gives an explicit replacement for Sawhney’s Lemma 2.1
by reducing the large-square contribution to a family of negative Pell equations. Combining these
bounds with Sawhney’s residue-class decomposition yields Theorem 1.

                                                ≤ C2,5 + 9.4N −1/4 .
                                        N        25
By Corollary 2(a),
                                        |A∗ |  23
                                              ≤ Cquad + 0.001973.
                                         N     25
Therefore
                           |A|  23      2
                               ≤ Cquad + C2,5 + 0.001973 + 9.4N −1/4 .
                            N   25      25
Using Lemma 2, (1), and N ≥ 2.64 × 1017 , we obtain

                           |A|
                               < 0.0376115 + 0.001973 + 0.000415 < 0.04.
                            N

Case 2: A∗ ̸= ∅ and A∗ consists only of odd elements. By Corollary 2(b),

                                        |A∗ |  23
                                              ≤ Cquad + 0.001973.
                                         N     50

Subcase 2a: A7 ∪ A18 contains no even elements. Then

                     A7 ⊆ {7, 57}       (mod 100),        A18 ⊆ {43, 93}   (mod 100).

Fix b ∈ A∗ . Since b is odd, among {7, 57} exactly one residue class gives 4 | (bt + 1), and among
{43, 93} exactly one residue class gives 4 | (bt + 1). Also 25 ∤ (bt + 1) on all four residue classes,
because t ≡ 7 or 18 (mod 25) whereas b ∈ A∗ implies b ̸≡ 7, 18 (mod 25). These two classes

contribute at most 2(N/100 + 1) elements. On the remaining two residue classes, Corollary 1 with
q0 = 100 applies and yields

                           |A7 ∪ A18 |   1  1                   2
                                       ≤   + C2,5 + 10.6N −1/4 + .
                               N         50 50                  N
Hence
                   |A|  23       1  1                              2
                       ≤ Cquad +   + C2,5 + 0.001973 + 10.6N −1/4 + .
                    N   50       50 50                             N
Using Lemma 2, (1), and N ≥ 2.64 × 1017 , we obtain

                      |A|
                          < 0.0356927 + 0.001973 + 0.000468 + 10−17 < 0.04.
                       N

Subcase 2b: at least one of A7 or A18 contains an even element. Without loss of generality, assume
A7 contains an even element and pick b′ ∈ A7 even. Pick any b ∈ A∗ . Since b ̸≡ 7 (mod 25), we
have 25 ∤ (7b + 1), so Corollary 1 applies to A7 with the odd witness b and gives

                                     |A7 |  1
                                           ≤ C5 + 4.7N −1/4 ,
                                      N     25
while b′ ≡ 7 (mod 25) implies 25 ∤ (18b′ + 1), so applying it to A18 with the even witness b′ gives

                                    |A18 |  1
                                           ≤ C2,5 + 4.7N −1/4 .
                                     N      25
Therefore
                     |A|  23       1   1
                         ≤ Cquad + C5 + C2,5 + 0.001973 + 9.4N −1/4 .
                      N   50      25   25
Using Lemma 2, (1)–(2), and N ≥ 2.64 × 1017 , we obtain

                          |A|
                              < 0.0334755 + 0.001973 + 0.000415 < 0.04.
                           N

Case 3: A∗ = ∅ and both A7 and A18 are nonempty. Pick b ∈ A7 and b′ ∈ A18 . Since b ≡ 7
(mod 25) and b′ ≡ 18 (mod 25), we have 25 ∤ (18b + 1) and 25 ∤ (7b′ + 1). Thus Corollary 1 with
q0 = 25 applies to A7 (using b′ ) and to A18 (using b), yielding

                                     |A|  2
                                         ≤ C5 + 9.4N −1/4 .
                                      N   25
Using (2) and N ≥ 2.64 × 1017 , we obtain

                                |A|
                                    < 0.0293395 + 0.000415 < 0.04.
                                 N
   All cases give |A| /N < 1/25, which finishes the proof.
